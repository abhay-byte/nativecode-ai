```text

NC_HOST_TMP=/data/data/com.zenithblue.nativecode/files/usr/tmp

```

### 3.3 Mount SSOT (idempotent)

Function `ensure_mounts`:

1. Resolve busybox (KSU/Magisk/system only — **never** app/termux busybox).  
2. Soft remount `/data` `dev,suid` via `/system/bin/mount` then BB (fail soft).  
3. For each bind (`/dev`, `/sys`, proc, devpts, shm, sdcard, host-tmp):  
   - if already mounted on exact target → **skip**  
   - else mount once  
4. Sticky `/tmp`: if mounted as wrong bind → umount once; `chmod 1777`; **never** bind host over `/tmp`.  
5. Copy `launch_tool.sh` from host-tmp → guest `/tmp` if present.  
6. Optional flag `--x11` for GUI only: bind `$PREFIX/tmp/.X11-unix` → guest `/tmp/.X11-unix` (used by GUI script, not default terminal).

**Critical:** never remount everything blindly on every call.

### 3.4 Guest entry SSOT

| Mode | Implementation |
|------|----------------|
| `login --user flux` | mounts; `chroot $ROOT /bin/su - flux` (or `su - flux -s /bin/zsh`) interactive |
| `login --user root` | mounts; `chroot … /bin/bash -l` or `su - root` |
| `sh --user U -- '…'` | mounts; **base64 or single-quoted** payload into `su - U -c` **or** `bash --noprofile --norc -c` as root then `runuser`/`su` **once** |
| `exec --user U -- CMD args` | mounts; `chroot … env -i … su - U -c 'exec "$@"'` with **proper** quoting (prefer `chroot … /usr/bin/env` + argv via `su` only when needed) |
| `b64 --user U -- B64` | mounts; `echo B64 \| base64 -d \| bash` as user U (replaces RootShell inline) |

**Never** implement app path as: runner already `su - root -c` + outer `/bin/su - flux -c multi-word` without a dedicated `sh --user flux`.

Recommended guest non-interactive:

```sh
# as root inside chroot once:
if [ "$USER" = root ]; then
  exec /bin/bash --noprofile --norc -c "$CMD_STR"
else
  exec /bin/su - "$USER" -s /bin/bash -c "$CMD_STR"
fi
```

Use `printf %s` + base64 for Kotlin→shell for anything with `$` `` ` `` quotes newlines.

### 3.5 Kotlin SSOT usage

#### A. `ChrootCommandBuilder.build`

```text
ensureLauncherScript(ctx)  # keep host-side launch_tool writer

interactive (exec zsh | bash --login | blank):
  rootInner = "exec $CHROOT_HELPER login --user $user [--shell zsh]"

non-interactive simple:
  rootInner = "exec $CHROOT_HELPER sh --user $user -- '$escaped'"

non-interactive complex:
  stage host script OR base64:
  rootInner = "exec $CHROOT_HELPER b64 --user $user -- $b64"

wrap:
  winch trap + RootShell.shellRootCommand(rootInner)
  argv = [SESSION_EXEC, "-c", winchCmd]
```

Delete inline `mountCmds` and all `busybox chroot` fallbacks once helper always staged.

#### B. `RootShell.executeInChroot` / `captureInChroot`

```text
inner = "$CHROOT_HELPER b64 --user $user -- $b64"
// or sh --user if short+simple
execute(inner) / captureResult(inner)
```

Delete `chrootMountPrep` private duplicate.

#### C. MainActivity `chroot_guest`

```text
stage script into CHROOT/tmp via RootShell or helper
rootInner = "$CHROOT_HELPER sh --user root -- 'bash /tmp/$scriptName …'"
// use shellRootCommand — not hardcoded /system/bin/su
```

#### D. PackageInstallRunner / CliToolsInstaller / Onboarding

All guest exec → helper only. Host tree stage (`cp` into `CHROOT/tmp`) may stay host-root without chroot (file ops only) — OK.

#### E. GUI

`start_debian13_gui.sh` phase 1: `nativecode_chroot.sh mount --x11` then guest XFCE via  
`nativecode_chroot.sh sh --user flux -- '… startxfce4 …'`  
or keep long guest block but **mounts only** from SSOT.
