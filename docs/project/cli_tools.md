## Key Insights (July 2026)
* **Antigravity CLI**: Replaced Gemini CLI's free tier in June 2026. Closed-source harness tied to the Google ecosystem.
* **Claw Code**: Emerging open-source clean-room architecture rewrite of Claude Code following a source leak in March 2026. High community adoption.
* **Model Agnostic vs. Vendor Native**: Tooling divides between harnesses (Aider, OpenCode, Pi) running arbitrary provider APIs and proprietary endpoints (Claude Code, Codex, Antigravity, Grok Build).
